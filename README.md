# Metrobee Homebrew Tap

Metrobee ametlik macOS Homebrew tarkvaravaramu.

---

## 1. Varamu lisamine

```bash
brew tap metrobee/homebrew-tap
```

---

## 2. Saadaolevad Valemid (Formulae)

### `seen` / `plutoff`
PlutoFF: Professionaalne ja ülikiire macOS CLI seene- ja taimevaatluste sisestamiseks otse terminalist PlutoF / eElurikkuse registrisse.

```bash
# Paigalda seen CLI
brew install seen

# või täispika nimega
brew install plutoff
```

#### Omadused:
- Lühikesed lipud: `s:` (substraat), `t:` (tüüp), `o:` (ohtrus), `kv:` (kaasvaatlejad), `m:` (märkus).
- ZSH Tab-automaatlõpetus parameetritele ja puuliikidele.
- Apple Photos otsetugi ja natiivne HEIC teisendus.
- Automaatne pilvesünkroon aadressile [https://fungib.web.app](https://fungib.web.app).
